# Security Policy

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on this repository.

We aim to acknowledge reports within 3 business days and to ship a fix for confirmed
high/critical issues within 7 days. Fixes are released as patch versions, which client
projects receive automatically through Renovate.

## Supported versions

Only the latest minor version receives security fixes.
